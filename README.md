# BuildMintZ Shield

A lightweight, local-only browser extension for blocking requests to known ad, tracking, and scam domains, and hiding common ad containers.

## What it does
- **Blocks Network Requests:** Blocks known ad and tracker domains.
- **Cosmetic Filtering:** Hides common ad containers.
- **YouTube Ad Skipping:** Instantly skips pre-rolls and mid-rolls.
- **Ad-Slip Diagnostics:** Records DOM signals if an ad slips through.

## Install
Run `npm run build` then load the `dist/chrome-unpacked/` folder in Chrome extensions.
